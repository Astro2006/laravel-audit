# Task: Accessibility

## Mission

A static accessibility review against WCAG 2.2 AA.

## Inputs

- The frontend map (below, from another task)
- Layouts, forms, navigation, modals and shared components in `resources/views` / `resources/js`

## Checklist

- Inputs without labels, images without `alt`, icon-only buttons without accessible names, clickable `div`/`span` instead of buttons or links, broken heading hierarchy, `outline-none` without a visible focus replacement, state communicated by color only, missing `lang` attribute, modals without focus management. Group by problem, list the files. (`accessibility`)
